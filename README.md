# TripAdvisor Clone

A full-stack TripAdvisor clone built with React, Vite, Express, and SQLite.

## Features
- **Home Page**: Hero search, popular destinations, and featured listings.
- **Search Page**: Filter by category, rating, and price.
- **Place Detail**: Image gallery, detailed description, and reviews.
- **Reviews**: Users can rate and comment on places.
- **User Auth**: Simple login system using local storage.
- **Admin Panel**: Add and delete places, manage listings.
- **Maps**: Integrated OpenStreetMap for location visualization.

## Tech Stack
- **Frontend**: React, Tailwind CSS, Lucide Icons, Framer Motion.
- **Backend**: Node.js, Express.
- **Database**: SQLite (via `better-sqlite3`).

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```

## Deployment to GitHub
```bash
git init
git add .
git commit -m "TripAdvisor Clone"
git branch -M main
git remote add origin https://github.com/USERNAME/tripadvisor-clone.git
git push -u origin main
```
